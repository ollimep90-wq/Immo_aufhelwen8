Für den Zugang zu Kundendaten brauchst du zusätzlich einen Code vom Handy. Einmalig einrichten:

  1. Authenticator-App öffnen (z. B. Google Authenticator, Microsoft Authenticator, 2FAS oder der Passwortmanager).
  2. Den QR-Code scannen oder den Schlüssel von Hand eintragen.
  3. Den angezeigten 6-stelligen Code unten eingeben.
